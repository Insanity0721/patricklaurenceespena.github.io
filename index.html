Case Study: Terra Education Portal & CMS

Problem & Context:

Managing extensive education workflows required dynamic web forms, reliable database querying, synchronizing records with Salesforce, and troubleshooting client data across varied spreadsheets.

Architecture & Solution:

Constructed PERN applications using React.js frontend structures, Node.js backend logic, and PostgreSQL database operations. Introduced AWS Lambda serverless functions to automate backend event handling and integrated Typeform API for responsive dynamic form submission pipelines.

Observability & Error Resolution:

Integrated Datadog API for performance monitoring, error tracking, and Session Replay to accurately capture user friction points. Automated incident tickets directly into Jira for rapid triage, while utilizing Slack for real-time team coordination.

Data Realignment & Management:

Addressed and reconciled client-provided spreadsheet records with customer databases, resolving discrepancies in payment statuses and Salesforce synchronization.
